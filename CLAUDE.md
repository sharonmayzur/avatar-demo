# Project: Avatar Demo

## What This Is
A collection of HTML demos and UI prototypes for the OTT streaming platform frontend.
Each demo lives in its own folder and is self-contained.

## Folder Structure
- `avatar/` — Avatar UI demo
- `micro-drama4/` — Micro-drama UI demo (latest)
- `FE alternative/` — FE alternatives comparison

## Rules for New HTML Demos
- Every new demo gets its own dedicated folder: `/Users/sharonmayzur/Documents/GitHub/avatar-demo/<demo-name>/`
- The folder must contain: `index.html` + any related assets (CSS, JS, images)
- Make demos self-contained — no external dependencies if possible (inline CSS/JS)
- After creating/editing any HTML, commit and push to GitHub automatically

## Style Defaults
- Visually polished, modern UI
- Mobile-friendly where relevant
- Use inline styles or a single `<style>` block — no separate CSS files unless the demo is complex

## GitHub
- Repo: https://github.com/sharonmayzur/avatar-demo
- Always commit with a clear message describing what the demo is
- Push to main branch
